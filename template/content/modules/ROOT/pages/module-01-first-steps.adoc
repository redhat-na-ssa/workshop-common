== Exercise 1: Create a Project

. Create a project for the exercises:
+
[source,bash,role=execute]
----
oc new-project workshop-first-steps
----

. Start a sample app in it:
+
[source,bash,role=execute]
----
oc new-app \
  --name hello \
  --image registry.access.redhat.com/ubi9/httpd-24 \
  --namespace workshop-first-steps
----

. Check that the app's pod is running:
+
[source,bash,role=execute]
----
oc get pods \
  --namespace workshop-first-steps
----
+
The `hello` pod shows `Running`.
