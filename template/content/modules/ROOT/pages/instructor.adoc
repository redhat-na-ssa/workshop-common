== Environment and Requirements

Each workshop lists the cluster components, Operators, command-line tools, roles and access it needs on its own page.
Prepare everything for the workshops you deliver:

// add-workshop.py adds workshops above this line

Shared by all the workshops: attendees who don't want to install the command-line tools run the workshop CLI tools image on the cluster, as xref:cli-tools.adoc[Shared CLI tools] describes.
Make sure attendees can pull that image, or mirror it for a disconnected cluster.

xref:downloads.adoc[Downloads] has every file of the release: the PDF, the Helm chart, the list of images to mirror and the guide for running the workshop in a disconnected cluster.
<<deploy-the-workshop,Deploy the Workshop>> shows how to deploy them.

== Before the Day

. Prepare the environment from the setup requirements above, for every attendee.
. Deploy the workshop, as <<deploy-the-workshop,Deploy the Workshop>> describes.
. Run the workshop end to end once on an environment built the same way.
. Send attendees the xref:attendee.adoc[Workshop Attendee Guide] page so they can check their workstation.
