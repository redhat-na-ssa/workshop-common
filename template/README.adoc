== Working on the Workshop

The pages are in `content/modules/ROOT/pages`, and `content/modules/ROOT/nav.adoc` lists them in order.
The site look and the build workflows come from https://github.com/@@OWNER@@/workshop-common[workshop-common], so change those there.

Every pull request runs *Check content*, which holds the lines it changes to the formatting conventions and checks that the site builds without warnings or broken links, and *Test PDF Build*.
A merge to `main` publishes the site.

To preview the site locally:

[source,bash]
----
npx --yes \
  --package @antora/cli@3.1 \
  --package @antora/site-generator@3.1 \
  --package @asciidoctor/tabs@1.0.0-beta.6 \
  antora default-site.yml
----

[source,bash]
----
python3 -m http.server 8080 \
  --directory www
----

Then open http://localhost:8080/.
