== Working on the Workshop

The pages are in `content/modules/ROOT/pages`, and `content/modules/ROOT/nav.adoc` lists them in order.
The site look, the PDF look and the build workflows come from https://github.com/@@OWNER@@/workshop-common[workshop-common], so change those there.

Every pull request runs *Check content*, which holds the lines it changes to the formatting conventions and checks that the site builds without warnings or broken links, and *Test PDF Build*.
A merge to `main` publishes the site.

To preview the site locally, with https://github.com/@@OWNER@@/workshop-common[workshop-common] checked out next to this repo, run this from this repo's folder:

[source,bash]
----
../workshop-common/scripts/preview.sh --watch
----

It builds the site the way the Pages workflow does, serves it on http://localhost:8080/ and rebuilds it when you save a change.
It needs Node.js and Python 3.

== Releases

To publish a release with its PDF, run the *Build and Release PDF Documentation* workflow from the Actions tab with the next version, such as `v1.0.0`, or push a tag of that name.
